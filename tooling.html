1. Клиенты

psql, pgcli, DBeaver, PyCharm

CLI-классика и GUI-альтернативы.

# psql — стандартный, есть везде:
psql -h 127.0.0.1 -U postgres -d app

# pgcli — CLI с автодополнением и подсветкой:
pip install pgcli
pgcli postgres://user:pass@host/db

# DBeaver — кросс-платформенный GUI, поддерживает все мажорные СУБД.
# PyCharm/IntelliJ — встроенные Database Tools, удобны внутри IDE.

Хитрости psql и pgcli

Метакоманды, которые сильно сокращают рутину.

\timing on                       -- показывать время выполнения каждого запроса
\watch 2                         -- повторять последний запрос каждые 2 секунды
\edit                            -- открыть последний запрос в $EDITOR
\copy users TO 'users.csv' CSV HEADER
\copy users FROM 'users.csv' CSV HEADER
\set ECHO_HIDDEN on              -- показывать SQL за метакомандами (\d и т. д.)
\gexec                           -- выполнить результат предыдущего SELECT как SQL
\set HISTSIZE 100000             -- увеличить историю команд
\x auto                          -- авто-режим расширенного вывода
\d   users                       -- описание таблицы
\d+  users                       -- + размеры и комментарии
\df  myfunc*                     -- список функций по маске
\sf  myfunc                      -- показать тело функции
\ef  myfunc                      -- открыть функцию в редакторе

\copy идёт через клиент (используй для локальных файлов), серверная COPY — через сервер. \gexec очень полезен для метапрограммирования: например, «сгенерировать DROP-команды для всех таблиц схемы» — но требует осторожности.

2. .pgpass

Безопасное хранение паролей

Файл ~/.pgpass избавляет от повторного ввода пароля и не светит его в process list.

# ~/.pgpass
# формат: hostname:port:database:username:password
127.0.0.1:5432:*:postgres:secret
prod-db.example.com:5432:app:app_user:abc123def
*:*:replica_db:replicator:repl_secret

# Права обязательны (иначе psql проигнорирует файл):
chmod 600 ~/.pgpass

# Теперь подключение без -W:
psql -h 127.0.0.1 -U postgres -d app

# Альтернатива — переменные:
export PGPASSWORD=secret    # видна в `ps -ef`, лучше избегать
export PGUSER=postgres
export PGDATABASE=app

* — wildcard в любом поле. На Windows файл лежит в %APPDATA%/postgresql/pgpass.conf и про права заботиться не нужно.

3. Размеры БД, таблиц, индексов

Сколько весят данные

Функции pg_database_size, pg_total_relation_size, pg_size_pretty.

-- размер каждой БД:
SELECT datname,
       pg_size_pretty(pg_database_size(datname)) AS size
FROM   pg_database
ORDER  BY pg_database_size(datname) DESC;

-- топ-20 таблиц по полному размеру:
SELECT n.nspname || '.' || c.relname              AS rel,
       pg_size_pretty(pg_total_relation_size(c.oid))  AS total,
       pg_size_pretty(pg_relation_size(c.oid))        AS heap,
       pg_size_pretty(pg_indexes_size(c.oid))         AS indexes
FROM   pg_class c
JOIN   pg_namespace n ON n.oid = c.relnamespace
WHERE  c.relkind = 'r'
  AND  n.nspname NOT IN ('pg_catalog','information_schema')
ORDER  BY pg_total_relation_size(c.oid) DESC
LIMIT  20;

-- размер каждого индекса конкретной таблицы:
SELECT i.indexrelname,
       pg_size_pretty(pg_relation_size(i.indexrelid)) AS size,
       i.idx_scan                                     AS uses
FROM   pg_stat_user_indexes i
WHERE  i.relname = 'orders'
ORDER  BY pg_relation_size(i.indexrelid) DESC;

pg_relation_size — только heap; pg_total_relation_size — heap + TOAST + индексы. Индекс с idx_scan = 0 на боевой системе — кандидат на удаление: место и стоимость записи он жрёт, пользы не приносит.

4. SQLite vs PostgreSQL

Когда SQLite — лучший выбор

Не любая задача требует Postgres. SQLite часто оптимальнее.

SQLitePostgreSQL
АрхитектураВстраиваемая, файл на дискеКлиент-сервер
Конкуренция записиОдин писатель, много читателейМного писателей и читателей
Размер данныхДо нескольких ГБ комфортноГБ–ТБ
ТипизацияType affinity (мягкая)Строгая
РасширенияFTS5, R-tree, JSON1Огромная экосистема
Где братьМобильные приложения, локальные кеши, тесты, CLI-утилитыПродовые бэкенды

SQLite — идеальная встраиваемая БД. Тащить Postgres в моб-приложение или в маленькую CLI-утилиту обычно не нужно. Зато ставить SQLite вместо Postgres в нагруженный веб-сервис — тоже не лучшая идея: один писатель быстро становится бутылочным горлышком.
