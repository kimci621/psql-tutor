# PostgreSQL Tutor — локальный учебник с ИИ-ментором

Офлайн-сайт для обучения PostgreSQL, в котором у каждой темы есть кнопка
«💬 Поучиться с ИИ», открывающая диалог с локальной языковой моделью
(LM Studio): ИИ сначала объясняет выбранную тему с примерами, затем проверяет
понимание и помогает разобраться через вопросы.

Сайт полностью статический: HTML/CSS/JS без сборки и без интернета.

## Запуск сайта

В корне проекта:

```bash
python3 server.py --port 8000
```

И открой <http://localhost:8000>.

`server.py` раздаёт статические файлы и проксирует запросы `/api/lmstudio/*`
в LM Studio на `http://127.0.0.1:1234`. Так браузер не блокирует чат из-за CORS.

> Можно открыть и через `file://` или `python3 -m http.server`, но тогда прямой fetch к LM Studio работает только при включённом CORS в LM Studio.

## Настройка LM Studio

1. Установи [LM Studio](https://lmstudio.ai/) и скачай модель. Хорошо подходят:
   - `Qwen2.5-7B-Instruct` или `Qwen2.5-Coder-7B-Instruct`
   - `Llama-3.1-8B-Instruct`
   - любая другая instruct-модель, понимающая русский
2. Открой вкладку **Developer → Local Server**.
3. Загрузи модель, нажми **Start Server**. По умолчанию — `http://localhost:1234`.
4. Проверь, что сервер отвечает:
   ```bash
   curl http://127.0.0.1:1234/api/v1/models
   ```

В шапке панели чата нажми ⚙ → **Найти модели**, чтобы автоматически подставить id.

## Альтернатива: Ollama

Сайт ожидает OpenAI-совместимый endpoint. У Ollama он живёт по адресу `http://localhost:11434/v1`. В настройках сайта замени Base URL и укажи имя модели (например, `qwen2.5:7b-instruct`).

## Особенности

- История диалога сохраняется в `localStorage` отдельно для каждой темы — можно вернуться через неделю и продолжить.
- Кнопка ↺ в панели чата сбрасывает текущий диалог.
- Тёмная и светлая темы.
- Никакой телеметрии и сетевых обращений, кроме запросов к LM Studio на `localhost`.
