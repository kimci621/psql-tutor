Как получить список таблиц

В PostgreSQL есть три рабочих способа узнать, какие таблицы существуют: метакоманды psql, представления information_schema и системный каталог pg_catalog. Каждый из них показывает чуть разный срез: то, что доступно тебе, то, что находится в нужной схеме, то, что вообще существует на сервере.

1. Самый быстрый способ — psql

Метакоманды на бэкслеше — это сахар над запросами к каталогу. Удобно в интерактиве.

\dt              -- таблицы текущей схемы (по search_path)
\dt+             -- + размер и описание
\dt public.*     -- все таблицы в схеме public
\dt *.*          -- все таблицы во всех схемах
\d  users        -- описание таблицы users (столбцы, индексы, ограничения)

2. Через information_schema

Стандарт SQL — переносится между СУБД. Показывает только то, к чему у тебя есть права.

SELECT table_schema, table_name
FROM   information_schema.tables
WHERE  table_type = 'BASE TABLE'
  AND  table_schema NOT IN ('pg_catalog','information_schema')
ORDER  BY table_schema, table_name;

3. Через pg_catalog.pg_tables

Postgres-специфично, но компактно и удобно для скриптов.

SELECT schemaname, tablename, tableowner
FROM   pg_catalog.pg_tables
WHERE  schemaname NOT IN ('pg_catalog','information_schema')
ORDER  BY schemaname, tablename;

Размер каждой таблицы

Полный размер вместе с TOAST и индексами.

SELECT n.nspname                                             AS schema,
       c.relname                                             AS table,
       pg_size_pretty(pg_total_relation_size(c.oid))         AS total,
       pg_size_pretty(pg_relation_size(c.oid))               AS heap,
       pg_size_pretty(pg_indexes_size(c.oid))                AS indexes
FROM   pg_class c
JOIN   pg_namespace n ON n.oid = c.relnamespace
WHERE  c.relkind = 'r'
  AND  n.nspname NOT IN ('pg_catalog','information_schema')
ORDER  BY pg_total_relation_size(c.oid) DESC
LIMIT  20;

pg_total_relation_size учитывает индексы и TOAST. pg_relation_size — только основной heap.

Подводные камни

  • information_schema скроет таблицы, к которым у текущей роли нет ни одного права. pg_catalog.pg_tables покажет их в любом случае.
  • pg_tables содержит только обычные таблицы. Чтобы увидеть представления, материализованные представления и партиционированные таблицы, фильтруй pg_class.relkind по нужным значениям (r, v, m, p).
  • search_path влияет только на «короткие» имена. Полное имя schema.table работает всегда.
